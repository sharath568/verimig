# Editing the paper

```
paper/
  main.tex           preamble, title, authors, \input of each section  (rarely edited)
  defaults.tex       result macros (red [TBD] until analyze.py runs) + \note{} helper
  sections/          ONE FILE PER SECTION -- this is where you write
    00-abstract.tex  01-introduction.tex  02-related-work.tex  03-taxonomy.tex
    04-framework.tex 05-setup.tex  06-results.tex  07-discussion.tex  08-conclusion.tex
  refs.bib           all references, grouped by topic, with instructions at the top
  tables/            GENERATED by scripts/analyze.py -- do not hand-edit
  figures/           GENERATED by scripts/analyze.py -- do not hand-edit
```

## Build
- Locally: `cd paper && latexmk -pdf main.tex` (Mac: `brew install --cask mactex-no-gui`)
- Overleaf: zip the `paper/` folder, then New Project -> Upload Project. Compiler: pdfLaTeX.
  After each new run, re-upload `tables/` and `figures/`.

## Add a reference
1. Get BibTeX from Google Scholar (Cite -> BibTeX), dblp.org, or the publisher page.
2. Paste it into `refs.bib` under the matching topic and give it a short key, e.g. `smith2025sqlmig`.
3. Cite it in a section: `\cite{smith2025sqlmig}`, or for several at once `\cite{a,b,c}`.
4. Rebuild. IEEEtran numbers and formats references automatically, in order of first citation.
   Uncited entries are left out of the PDF.

## Add a figure or table
- Figure: put `myfig.pdf` in `figures/`, then
  `\begin{figure}[t]\centering\includegraphics[width=\columnwidth]{figures/myfig.pdf}\caption{...}\label{fig:my}\end{figure}`
- Full-width figure or table: use `figure*` / `table*` (these float to the top of a page).
- Refer to them with `Fig.~\ref{fig:my}` and `Table~\ref{tab:my}`.

## Numbers
Never type a result into the text. Use the macros (e.g. `\AgenticEquiv\%`). If you need a new number,
add it in `scripts/analyze.py` (`macros.update(...)`) and declare a `\tbd` default in `defaults.tex`.

## The 6-page limit
- IEEE conference limit is usually 6 pages **including references** (check your CFP).
- To see the real length, hide the blue notes: in `defaults.tex`, move the line
  `\renewcommand{\note}[1]{}` so it comes *after* the `\newcommand{\note}...` line.
- If you are over: shorten the related work first, then move the per-category figure out.
  Don't shrink fonts or margins -- IEEE checks the template.
- Before submitting, search the PDF for "[TBD]" and "[Note" -- both must return nothing.
