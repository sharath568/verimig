\section{Conclusion}\label{sec:conclusion}

Compiling is a weak proxy for a correct database migration. VeriMig turns the conversion, testing, and
data-validation stages of the established migration lifecycle into measurable gates, and shows how much of
an LLM's apparent success depends on which gate judges it. Future work will extend the corpus with
anonymised production procedures, add SSMA output as a converter, and run G3 directly against an ASE oracle.
